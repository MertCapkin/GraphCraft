# Unity UI Core (UGUI)

Meta-UI primitives for Unity Canvas. Copy `Runtime/` + asmdef into your project's `Assets/GraphCraft/UI/`.

| Design graph | File |
|--------------|------|
| `component:button-primary` | `Runtime/Components/ButtonPrimary.cs` |
| `screen:login` | `Runtime/Screens/LoginScreen.cs` |

```bash
graphcraft ui tokens emit unity
graphcraft ui validate unity
```

Requires **UnityEngine.UI** (UGUI). UI Toolkit variant planned later.
